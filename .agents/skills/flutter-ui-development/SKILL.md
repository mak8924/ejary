# Flutter UI Development

## Workflow

1. Inspect existing theme and localization systems.
2. Identify reusable components.
3. Design the screen layout.
4. Implement responsive widgets.
5. Apply centralized theme colors and typography.
6. Add Arabic and English translations.
7. Handle RTL and LTR.
8. Implement loading, error, and empty states.
9. Add meaningful animations.
10. Verify both themes and both languages.

## Design Rules

- Prefer clean and modern layouts.
- Maintain consistent spacing.
- Use reusable components.
- Avoid hardcoded colors and strings.
- Use directional alignment and padding.
- Ensure accessible touch targets.
- Avoid unnecessary visual decoration.
- Keep screens lightweight.
- Ensure all interactions work.

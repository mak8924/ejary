# Coding Standards

1. Follow official Dart style guidelines.
2. Use meaningful class, method, and variable names.
3. Prefer const constructors whenever possible.
4. Use null safety correctly.
5. Avoid dynamic unless absolutely necessary.
6. Keep methods short and focused.
7. Avoid duplicate code.
8. Separate UI, business logic, and data operations.
9. Handle errors explicitly.
10. Never use print() for production logging.
11. Never leave unfinished required functionality.
12. Use reusable widgets.
13. Avoid oversized controllers and screens.
14. Run dart format and flutter analyze after implementation.
15. Fix all errors before completing a phase.
16. Use clear and consistent file naming.
17. Avoid unnecessary dependencies.

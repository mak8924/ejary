# UI/UX Guidelines

1. Build a modern, premium, minimal interface.
2. Support Light and Dark themes.
3. Support Arabic RTL and English LTR.
4. Never hardcode colors inside screens.
5. Never hardcode user-facing strings.
6. Use centralized typography and spacing.
7. Use directional padding and alignment.
8. Maintain consistent component styles.
9. Add loading, error, empty, and success states.
10. Use subtle animations only when useful.
11. Every button must have a functional action.
12. Ensure responsive layouts.
13. Maintain sufficient color contrast.
14. Use reusable buttons, inputs, cards, and PIN components.
15. Check both themes and both languages before completing a feature.
16. Use accessible font sizes and touch targets.
17. Avoid unnecessary visual decorations.
